How a month is calculated

  1. Each timesheet cell is one session. Morning am_0900_1330 and afternoon pm_1330_1800 are each 4 hours (0.5 day).
  2. Session count for the month = calendar days × 2. A 30-day month has 60 sessions. A 31-day month has 62.
  3. Use the salary row with the latest effective_date on or before that month.
  4. Session rate = monthly salary ÷ session count. Hourly rate = session rate ÷ 4.
  5. Project cost = session rate × sessions coded to that project. Admin is a project and goes to cost centre CC-ADMIN.
  6. AL, SL, CL, PH and OFF are paid leave and rest. They are not charged to a project.
  7. A blank cell is paid and unallocated. It raises a warning.
  8. NPL is no-pay leave. Deduct session rate × NPL sessions from net pay.
  9. Check: project cost + leave and rest + missing + NPL deduction = gross salary.

Worked example

Salary 30,000 in a 30-day month → 60 sessions → 500 per session (125 per hour).

Morning on one project and afternoon on another → 500 each.

Both sessions on the same project → 1,000.
