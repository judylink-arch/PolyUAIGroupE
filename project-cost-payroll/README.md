# Project Cost Payroll (HR1 / HR2)

Workshop HTML prototype for timesheet cost allocation and Salary (Actual) style reporting.

## Open
Open `index.html` in a browser (keep `xlsx.full.min.js` in this folder).

## Roles
- **HR1**: import projects/staff, enter timesheet, Staff Check Summary Excel (no salary access)
- **HR2**: import Pay History column Y, calculate, Salary (Actual) / Project Analysis Excel
