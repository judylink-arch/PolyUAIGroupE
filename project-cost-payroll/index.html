Allocation rule

Month base = days in month × 2. Denominator = base − (AL + SL + NPL + PH + OFF + Admin + CL). For each staff, denominator must equal total project units. Cost = (project units ÷ denominator) × Pay History column Y. Half-day = 1 unit.
Base: 62 31 days × 2
